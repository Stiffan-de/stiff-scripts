# 🛡️ Ad Filter

Фильтр рекламы на основе внешних списков (EasyList, uBlock Origin, AdGuard). Работает на всех сайтах.

## ✨ Возможности

- 🌐 **Все сайты** — без привязки к конкретному домену.
- 📥 **4 источника списков** — EasyList, uBlock, YouTube Clear View, AdGuard Base.
- 🧠 **`:has-text()`** — скрытие по тексту, а не только по селектору.
- 🎯 **Свои правила** — формат `domain##selector`.
- 🚫 **Исключения** — сайты, где фильтр не работает.
- 🔄 **Автообновление** — каждые 6 часов.
- ⏱️ **Живая панель** — таймер до следующего обновления.
- 💾 **Кэш** — 24 часа.
- ⌨️ **Настраиваемые хоткеи** — `Alt+A`, `Alt+Shift+F`.

## 📥 Установка

1. Установи **Tampermonkey** или **Violentmonkey**.
2. Нажми **[Установить](https://raw.githubusercontent.com/StiffMusic/stiffmusic-userscripts/main/ad-filter/ad-filter.user.js)**.
3. Подтверди установку.

## 🎯 Использование

| Действие | Как |
|---|---|
| Открыть панель | `Alt+A` |
| Включить/выключить фильтр | `Alt+Shift+F` |
| Обновить списки | Кнопка в панели |
| Добавить правило | Меню Tampermonkey |
| Добавить исключение | Меню Tampermonkey |

## ⚠️ Ограничения

Это **не полноценная замена** uBlock Origin или AdGuard. Скрипт работает **на уровне CSS**, а не сети:

- ✅ Реклама не видна.
- ❌ Реклама всё равно загружается (тратит трафик).
- ❌ Трекеры всё равно работают.

Используй как **дополнение** к основному adblocker'у.
