# StiffMusic Userscripts

Коллекция пользовательских скриптов для Tampermonkey / Violentmonkey.

## 📦 Скрипты

### 🎬 YouTube PiP Button
Добавляет кнопку Picture-in-Picture в плеер YouTube и горячую клавишу `Alt+P`.

**[📥 Установить](https://raw.githubusercontent.com/StiffMusic/stiffmusic-userscripts/main/youtube-pip-button/youtube-pip-button.user.js)** · [📖 Описание](./youtube-pip-button/README.md)

### 🛡️ Ad Filter
Фильтр рекламы на основе внешних списков (EasyList, uBlock, AdGuard). Работает на всех сайтах.

**[📥 Установить](https://raw.githubusercontent.com/StiffMusic/stiffmusic-userscripts/main/ad-filter/ad-filter.user.js)** · [📖 Описание](./ad-filter/README.md)

## 🔧 Установка

1. Установи **Tampermonkey** (Chrome, Firefox, Edge) или **Violentmonkey** (Chrome, Firefox).
2. Нажми **«📥 Установить»** рядом с нужным скриптом.
3. Tampermonkey предложит установить — подтверди.
